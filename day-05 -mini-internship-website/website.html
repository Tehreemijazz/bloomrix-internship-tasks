Useful HTML Terms

HTML stands for HyperText Markup Language. It defines the structure of web pages.

A web page can use a variable such as pageTitle to represent a title in a programming example.

An example of a machine-readable value is: HTML Basics.

A long word can contain an optional line-break point: internshipdevelopmentprogram.

What did I learn in HTML basics?

I learned document structure, headings, paragraphs, links, images, lists, and basic form controls.

Why are semantic HTML tags important?

Semantic tags describe the purpose of page content. They help browsers, search engines, and assistive technologies understand the page structure.

What is the purpose of HTML forms?

Forms collect information from users through input fields, selection controls, and buttons.
